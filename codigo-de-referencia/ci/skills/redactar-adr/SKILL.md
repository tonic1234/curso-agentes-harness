# Redactar un ADR

1. Título corto con número correlativo: `NNNN-titulo.md` en `docs/adr/`.
2. Secciones, en este orden: Contexto, Decisión, Alternativas descartadas, Consecuencias.
3. Escribí por qué se descartó cada alternativa, no sólo cuál se eligió.
4. Estado: `propuesta`, `aceptada` o `reemplazada por NNNN`.
